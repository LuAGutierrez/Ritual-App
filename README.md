# Rituales — Momentos que acercan

App de rituales diarios en pareja. Next.js + Supabase.

## Desarrollo local

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000)

Variables de entorno: copiá `.env.example` a `.env.local` y completá las claves (Supabase, VAPID, cron).

## Stack

- **Next.js 14** (App Router) + TypeScript + Tailwind
- **Supabase** — auth, base de datos, realtime
- **Web Push** — avisos cuando responde la pareja y recordatorio diario
