# Rituales — Design System

## Visual Identity

The design language should feel:
- intimate, elegant, premium, calm, modern, emotionally warm.

The UI must feel:
- breathable, soft, minimal, intentional.

---

## Design Philosophy

Prefer:
- whitespace, typography hierarchy, subtle motion, clean cards, smooth transitions.

Avoid:
- visual noise, hard shadows, childish gamification, excessive gradients, crowded layouts.

---

## Motion Design

Use:
- slow transitions, soft fades, subtle scaling, smooth reveals.

Motion should support emotion, not excitement overload.

---

## Component Style

**Cards:** rounded, soft spacing, premium feel.

**Buttons:** simple, large tap areas, calm interactions.

**Inputs:** minimal, distraction-free.

---

## UX Principles

1. **One main action per screen** — avoid cognitive overload.
2. **Emotional focus** — every screen should support emotional clarity.
3. **Short interaction cycles** — interactions should feel lightweight.

---

## Typography

Prefer:
- elegant modern sans-serif, optional editorial serif accents.

Typography should carry emotional tone.

---

## Layout Principles

Mobile-first always.

Use:
- vertical rhythm, comfortable spacing, strong readability.

Avoid:
- dense dashboards, complex navigation, tiny interaction targets.

---

## Emotional UI

The interface should feel:
- emotionally safe, private, calm, premium, intentional.

The app should feel closer to a premium journal, a wellness app, or a luxury emotional companion — **not a casual game app**.
